# Phase Context Records

Create a context file only after an approved implementation phase begins, named `phase-XX-phase-name-context.md`.

Record material human decisions, architectural/API discoveries, invariants, accepted limitations, unresolved requirements, downstream findings, and superseded decisions with rationale/provenance.

Do not record chat transcripts, routine output, narration, harmless dead ends, duplicated canonical content, full code, credentials, or unsupported speculation. Link to the authoritative source instead of copying it.
